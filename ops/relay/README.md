# ממסר השמע – שלוחה 5 (קולות הקשר של נתב"ג)

השידור של LiveATC (`http://d.liveatc.net/llbg2`) מפנה לשרת שידור שמשתנה (למשל `s1-bos.liveatc.net`), וימות המשיח לא מקבלת אותו ישירות. הממסר מושך את השידור ומשדר אותו מחדש בכתובת קבועה אחת, שאותה מגדירים בימות המשיח.

השידור משמש באישור LiveATC.net, והקרדיט להם מופיע בשלוחה.

```
LiveATC ──(הפניה)──▶ s1-xxx.liveatc.net ──▶ relay.mjs ──▶ Tailscale Funnel (https) ──▶ ימות המשיח ──▶ שלוחה 5
```

## איך הממסר עובד

- **חיבור יחיד ל-LiveATC:** הממסר פותח חיבור אחד בלבד, גם כשמחוברים הרבה מאזינים.
- **רק כשיש מאזין:** הוא מתחבר כשמאזין נכנס, ומתנתק 30 שניות אחרי שהמאזין האחרון יוצא, כדי לא להעמיס על LiveATC.
- **עוקב אחרי הפניות:** כש-LiveATC מחליפים שרת, הכתובת בימות המשיח לא משתנה.
- **התחברות מחדש:** אם השידור נופל או נתקע 30 שניות, הממסר מתחבר מחדש לבד.
- **בלי תלויות:** Node בלבד. הקונטיינר רץ בלי root, עם `read_only`, `cap_drop: ALL` ומגבלת זיכרון.
- **בדיקות:** `/healthz` מחזיר את מצב הממסר, ו-`/metrics` מחזיר מדדים ל-Prometheus. הבדיקות האוטומטיות נמצאות ב-`tests/relay.test.mjs`.

## בדיקה על מכונה וירטואלית (VirtualBox)

1. **יוצרים מכונה ב-VirtualBox:**
   - Ubuntu Server 24.04, עם 2 מעבדים, 2GB זיכרון ו-20GB דיסק.
   - ב-Network בוחרים **Bridged Adapter**, כדי שלמכונה תהיה כתובת ברשת הביתית.
   - בהתקנה מסמנים **Install OpenSSH server**.
2. **מוצאים את הכתובת שלה:** במכונה מריצים `ip -4 addr`, ומחפשים כתובת כמו `192.168.1.60`.
3. **מ-WSL, מגדירים כניסה עם מפתח:**
   ```bash
   ssh-keygen -t ed25519            # אם עוד אין מפתח
   ssh-copy-id myuser@192.168.1.60
   ```
4. **ב-`ops/ansible/inventory.ini`:** מורידים את ה-`#` בשורה של `natbag-vm` ומתקנים את הכתובת ואת המשתמש.
5. **מריצים:**
   ```bash
   cd ops/ansible && ansible-playbook relay.yml --ask-become-pass
   ```
6. **בודקים במכונה:**
   ```bash
   curl -s localhost:8000/healthz
   curl -s --max-time 20 localhost:8000/llbg.mp3 -o t.mp3 && ls -lh t.mp3
   ```
   בתוך 20 שניות צריך להתקבל קובץ של כ-80KB.

## חשיפה לאינטרנט (בשביל ימות המשיח)

ימות המשיח צריכה להגיע לממסר מהאינטרנט. הדרך המומלצת היא **Tailscale Funnel**: הוא נותן כתובת https קבועה, בלי לפתוח פורטים בראוטר. Ansible כבר מתקין את Tailscale. במכונה עושים פעם אחת:

```bash
sudo tailscale up                 # מתחברים לחשבון Tailscale (קישור בדפדפן)
sudo tailscale funnel --bg 8000   # בפעם הראשונה הוא יבקש לאשר Funnel בחשבון
tailscale funnel status           # מציג את הכתובת
```

הכתובת שמכניסים בימות המשיח, בלשונית "שידור חי אינטרנטי":
```
https://<שם-המכונה>.<tailnet>.ts.net/llbg.mp3
```

**אם ימות המשיח מקבלת רק http:** מפנים בראוטר פורט, למשל 8000, לכתובת של המכונה. ב-inventory מגדירים `relay_bind=0.0.0.0`, ומשתמשים בכתובת `http://<ה-IP הציבורי שלכם>:8000/llbg.mp3`. החיסרון: ה-IP הביתי משתנה מדי פעם, ופורט פתוח בבית.
